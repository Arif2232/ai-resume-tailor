# Security

Please do not include API keys, real resumes, personal details, or exploit details in public issues or pull requests.

To report a problem privately, open the [security advisories page](https://github.com/Arif2232/ai-resume-tailor/security/advisories) and select **Report a vulnerability**.

When reporting, include the affected version, the potential impact, and steps to reproduce using synthetic data. Do not send credentials or other people's private documents.

This project is in the planning stage. Its proposed security controls have not yet been implemented or independently verified.
