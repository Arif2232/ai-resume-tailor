# Contributing

Thanks for helping build AI Resume Tailor. The project is in its planning stage; review the README and architecture notes before proposing a change.

1. Open an issue to discuss a substantial change or an uncertain design.
2. Fork the repository, create a branch, and keep each change focused.
3. Verify the affected behavior with appropriate tests. Describe any checks you could not run.
4. Open a pull request describing the change, why it helps, and how you tested it.

Use synthetic resumes, job descriptions, and credentials in examples and tests. Never commit API keys, real resumes, personal contact details, or other private data. Report security issues privately as described in [SECURITY.md](SECURITY.md).

Keep interfaces usable with a keyboard and screen reader, and explain any changes that affect privacy or supported file formats. Resume claims must come from the candidate's information or be confirmed by the candidate; suggestions are not verified facts.
